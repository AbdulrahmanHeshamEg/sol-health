# Data Dictionary

All data is **synthetic**, generated by `ml/sol_ml/simulate.py`. Real astronaut medical data is private;
the simulator encodes published spaceflight physiology at a level suitable for a prototype.

## Files
| File | Content |
|---|---|
| `data/demo/crew.json` | `mission` object + `crew[]` profiles (4 fictional astronauts) |
| `data/demo/telemetry.csv` | 7,200 rows = 4 astronauts × 75 days × 24 h |
| `data/demo/api_snapshots/*.json` | Saved API responses for frontend mock mode |

## Hourly telemetry (`telemetry.csv`)
| Column | Unit | Typical in-flight range | How simulated |
|---|---|---|---|
| `timestamp` | ISO | mission start 2026-08-31 00:00 | hourly |
| `astronaut_id` | — | UH-01..UH-04 | |
| `mission_day`, `hour` | — | 1..75, 0..23 | |
| `heart_rate` | bpm | 50–75 rest, up to ~130 exercise | personal baseline + circadian ±4, −7 asleep, +70×activity, noise σ 3 |
| `hrv_rmssd` | ms | 25–90 | baseline +12 asleep, −25×activity, σ 6 |
| `spo2` | % | 96–99 | baseline ~97.8, σ 0.6 |
| `resp_rate` | breaths/min | 12–18 rest | −1.5 asleep, +10×activity, σ 1 |
| `systolic_bp` / `diastolic_bp` | mmHg | 105–130 / 65–85 | circadian, −8/−5 asleep, exercise rise, σ 5/4 |
| `core_temp` | °C | 36.5–37.5 | circadian ±0.3, +0.6×activity, σ 0.12 |
| `pvt_reaction_ms` | ms | 220–300 | Psychomotor Vigilance Test reaction time while awake; carried forward during sleep |
| `activity_level` | 0–1 | 0 rest … 1 max | ~0.2 awake, 0.6–0.85 during exercise |
| `is_asleep` | 0/1 | 22:00–06:00 | shortened during sleep-debt episodes |
| `exercise_type` | text | none / resistive / aerobic | ARED (resistive) ~09:00, treadmill/cycle (aerobic) ~15:00, frequency from weekly plan |
| `fluid_intake_ml` | ml/h | ~150 awake | ≈3.0–3.5 L/day nominal (includes exercise replacement) |
| `cabin_co2_mmhg` | mmHg | 1.5–3 nominal | local ppCO2 at crew location; slow 5-day drift; spikes in CO2 episodes |
| `radiation_msv` | mSv/h | ~0.04 | assumed 1.0 mSv/day deep-space habitat (ISS ≈ 0.5 mSv/day), lognormal noise, + solar particle event on day 59 |
| `sim_ground_truth` | text | condition | **Simulator label, for evaluation only. The API drops it; never show it as a prediction.** |

## Crew profile (`crew.json → crew[]`)
`astronaut_id, name, role, agency, age, sex, mass_kg, prior_career_dose_msv, protein_g_per_kg,
vitamin_d_ng_ml, ared_minutes_week, aerobic_minutes_week, baseline{8 vitals + simulator params}`.
`baseline` vital values = median of awake, resting hours on mission days 1–3 (the calibration period).

## Condition signatures (per unit intensity; intensity 0.35–1.2, 3 h ramp in and out)
| Condition | Signature |
|---|---|
| sleep_deprivation | 2–5 h sleep lost the night before; HR +6, HRV −15, PVT +70 ms |
| dehydration | fluid intake −80 %; HR +14, SBP −14, DBP −6, HRV −10, temp +0.35 |
| co2_exposure | local ppCO2 +2.5…+6.7 mmHg; resp +4, HR +6, PVT +35 |
| cardiovascular_strain | HR +22, SBP +26, DBP +12, HRV −22 |
| fever_infection | temp +1.6 °C, HR +18, resp +4, HRV −18, SpO2 −1 |
| hypoxia | SpO2 −7, resp +6, HR +14 |

## Deconditioning cohort (training only)
1,500 simulated missions × 2–7 months. Monthly hip BMD loss ≈ 1.55 %/mo × (1 − 0.55 × ARED/360), adjusted for aerobic
exercise, vitamin D < 30 ng/ml, protein, sex and age, plus noise; clipped ≥ 0.05. Thigh muscle loss built the same way
(≈ 2.4 %/mo without resistive exercise). Ranges chosen to match the published 1–1.5 %/month hip BMD loss without countermeasures.
